DNAFORM-2099 — math rendering with 5 duplicated items on one page

DNAFORM-2099

Repro for DNAFORM-2099: math notation fails to render on DnA View Test / Test Preview, while the same question renders correctly in Browse Items, in OT and in PIEOneer. The difference between those pages is how many items share one page — which is what this page reproduces.

What this checks

Five identical items are mounted on the same page. Each item holds two interactions, and each prompt carries all four markup variants described below:

  • @pie-element/multiple-choice@latest — prompt with the four variants (n.M1–n.M4), plus latex in each answer choice (n.C1–n.C4).
  • @pie-element/extended-text-entry@15.1.11 — prompt with the same four variants (n.E1–n.E4).

That is 8 prompt expressions plus 4 choice expressions per item, 60 in total. All 60 should render as typeset math (no raw \(...\) delimiters, no duplicated/blank output).

Observed on the current player: the M and C expressions render in all five items; E1–E4 render only in the first one or two items and fail in the rest. Which items survive shifts between runs — it is a race, not a property of the content.

Markup variants under test

The two reported items differ in how their math is marked up. Both prompts carry all four combinations below, so it is visible whether the markup difference is what decides the outcome, or whether it is the element / page that decides it.

Variant Inner text Exponents Seen in
V1 no delimiters x^{3} Q1 / 6433355 — renders in DnA
V2 \( ... \) x^3 Q2 / 6433350 — fails in DnA
V3 no delimiters x^3 isolates the brace style
V4 \( ... \) x^{3} isolates the delimiters

If the markup is what matters, V1/V3 and V2/V4 will split. If the element is what matters, the M row will pass and the E row will fail regardless of variant.

How to report a broken expression

Every expression is prefixed with a unique red tag so it can be named exactly:

  • [2.M1] … [2.M4] — item 2's multiple-choice prompt, one per markup variant.
  • [2.C1] … [2.C4] — item 2's four answer choices.
  • [2.E1] … [2.E4] — item 2's extended-text-entry prompt, the same four variants.

The tag is repeated in the sentence itself, so it stays readable even where the surrounding markup is stripped. Just tell me the tags that render wrong — e.g. “3.E2 and 5.C4 are broken”.
