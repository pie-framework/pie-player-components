Author — Extended Text Entry not rendered after revisit (Vue) repro

Combination / versions under test (prod proxy https://proxy.pie-api.com/bundles/):
@pie-element/extended-text-entry@15.1.1-ext.42
@pie-element/complex-rubric@7.1.1-next.44
Expected bundle request: .../@pie-element/extended-text-entry@15.1.1-ext.42+@pie-element/complex-rubric@7.1.1-next.44/editor.js
What this reproduces

A client embeds pie-author inside a Vue page. The first visit renders Extended Text Entry fine. Navigating away unmounts pie-author (removed from the DOM); navigating back mounts a brand new pie-author. On that second mount the Extended Text Entry config (pp-pie-element-extended-text-entry-config) is no longer rendered — but calling render() on that element from the console paints it back.

  1. Click Mount author — ETE renders, bundle is fetched.
  2. Click Unmount author (simulates leaving the Vue page).
  3. Click Mount author again (simulates coming back). Bundle is not re-fetched (elements already in the global registry / customElements).
  4. Observe: ETE config area is blank on the second mount.
  5. Click Force render ETE config (or run window.eteConfig.render() in the console) — it paints back.
